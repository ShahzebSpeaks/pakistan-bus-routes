# Public data endpoints for Pakistani transit: what exists and what we may reuse

Researched on 2026-09-16. Only a handful of sample requests per service. No logins, captchas or paywalls were bypassed, and nothing was bulk-downloaded. `data/` was not changed.

**Licence note.** Under Pakistan's Copyright Ordinance 1962, government works are protected by copyright and are **not** public domain by default. None of the sites below grants an open licence. Plain facts (stop names, route numbers, times, fares) are not protected by copyright, but a compiled database or a designed map is. So for official PDFs we can **extract facts, cite the source and ask for confirmation**. We must not copy map artwork or third-party databases.

A "no endpoint" verdict means none was found through the public web pages, `robots.txt`, sitemaps or obvious CMS APIs. Transitland and the Mobility Database both need API keys, so we did not query them; no Pakistani GTFS feed is known.

## Practical guidance

- **Use now:** CDA route PDFs for Islamabad feeder-route stop order, trip counts, headways and first/last times. Mark the source `"official": true` and cite the exact PDF URL. Coordinates must still come from OSM.
- **Cite, but don't copy wholesale:** PMA and SMTA route maps and route index pages; metro-status.com, redbus.shop and rehbar.pk only as secondary corroboration.
- **Do not use:** safar.fyi embedded data, the Kentkart `service.kentkart.com` API, or TransPeshawar content, until we have written permission.

## How to ask for permission

Keep each email short. Say:

1. who we are (an open-source Pakistan bus-routes project);
2. what data we want (route IDs, stop names in order, timetables/headways; ideally a GTFS export);
3. the licence we would publish it under (see `DATA_LICENSE.md`);
4. that we will credit them and link back.

Offer to send corrections back to them. Ask for an explicit written grant (for example "you may redistribute under CC-BY 4.0 / ODbL") rather than a vague "ok".
