CDA Islamabad official route timetables - extraction report (2026-11-01)

Permission: the project owner states CDA has granted permission to reuse CDA's published transit data.

SOURCE
- 42 PDFs linked from https://www.cda.gov.pk/cdaTransitMap (links taken from the cached page research/cache/pma-timings/cda_tm.html):
  https://www.cda.gov.pk/Assets/metro_transit_route/<CODE>_Forward.pdf and _Backward.pdf for 21 codes:
  FR-01, FR-03A, FR-04, FR-04A, FR-05, FR-06, FR-07, FR-08A, FR-08C, FR-09, FR-10, FR-11, FR-12, FR-13, FR-14,
  FR-14A, FR-15, FRB-01, FRG-1, ST-01, ST-02.
- All 42 downloaded 2026-11-01 (HTTP 200, application/pdf, 1.6 s apart) to research/cache/cda-timetables/ (gitignored).
  Server Last-Modified of every route PDF is 25 Aug 2025, so as_of = "2025-08-25".
- Map V-08 was not downloaded: it is a map, not a timetable, and every route it covers that has a timetable is in the 42 PDFs.

METHOD
- Text extracted with pypdf 6.14.2 (text only; nothing rendered or executed). Text dumps and the scripts are in the
  session scratchpad, not in the repo.
- Every PDF is a machine-generated GTFS-style export: a header (CDA route id, short name, long name, direction,
  total trips, average headway) and then, for EVERY trip, the trip id, start time and arrival/departure time at every stop.
  Parsing was clean: the trip count matched the header in all 42 files, and there were no unparsed lines.
  (Some stop names run straight into the time with no space; the regex handles this.)
- Each file has one stop pattern for all its trips. Running times are the same on every trip (a template schedule:
  there is no peak-hour slowdown).
- Fields per record: departures (all trips, from the origin), first, last, trips, headway_min (median gap),
  headway_peak_min (gaps starting 07:00-09:59 or 16:00-18:59), headway_offpeak_min (all other gaps),
  headway_range_min, journey_min (median, origin departure to arrival at the last stop), last_arrival, stop_count,
  stop_offsets_min (arrival offset at every stop on the first trip, 0.1 min precision), source_url, as_of, official,
  changed_since_pdf, notes (flags + CDA header values).
- Route mapping: FR-xx and ST-xx map to islamabad-electric-feeder with the same id. CDA "FRB-01" (PIMS - Gulberg)
  maps to isb-rwp-metrobus BLUE, and "FRG-1" (PIMS - Barakahu) maps to isb-rwp-metrobus GREEN.
- Output: research/incoming/cda-timetables.json, 42 records, 2,823 departures. JSON validated (parses).

FINDINGS / PROBLEMS
- No weekday / Friday / Sunday variants: each PDF has a single daily schedule, and no service days are stated.
  ST-01 and ST-02 are weekend-only according to the CDA map and our data. The PDFs don't say so.
- Changed since the PDFs (records kept, flagged changed_since_pdf=true):
  * FR-13: discontinued 20 Oct 2026 (ProPakistani). The PDF is historical.
  * FR-10: the PDF runs Golra Morh <-> Taxila (25 stops, about 75-80 min). Since 20 Oct 2026 it runs only Golra - B-17;
    the data route already has 20 stops to B-17.
  * FR-09 and FR-14: the PDFs give 15 min. Since 3 Sep 2026 they run every 12 min (TechJuice), and our data already says 12.
  * FR-08B has no CDA PDF (it is not on the timetable page).
- Outdated or conflicting PDF patterns:
  * FR-01 Forward: a truncated 17-stop NUST -> MCI Model School pattern. Backward is the full 26-stop Khanna Pul -> NUST.
  * FR-03A: the PDF still shows PIMS <-> Flower Market (13 stops, 10 min). Data and the CDA map say PIMS - Saidpur Village,
    with a 20 min headway in data.
  * FR-05: the PDF shows NUST <-> D-12 (14 stops, 5 min), but the header long name and the route table say
    Golra Morh - Taxila. Data is "unverified".
  * FR-06: the PDF ends at Golra Sharif. The map shows an extension to E-11 Markaz.
  * FR-11: the PDF ends at Rafiullah Shaheed Chowk (10 stops). Data runs to I-16/4 (20 stops).
  * FR-08A Forward: SUSPECT. Its 209 trips are a 20-min series (06:00-22:00) overlaid with a 5-min series (08:40-22:00),
    giving 40 duplicate times. Backward has 46 trips at 20 min. Use 20 min.
- Agreement with data/systems: headways match for FR-01, 04, 04A, 06, 07, 08A (backward), 08C, 10, 11, 12, 13, 14A, 15,
  ST-01, ST-02, BLUE and GREEN. Stop counts match in most directions. Backward patterns of FR-14A, FRB-01, FRG-1,
  ST-01 and ST-02 have 1-3 more stops than the data's one-direction stop list (the return paths differ).
- Data hours in data/systems agree with the PDFs. For example: FR-12 07:00-19:00, FR-13 06:00-19:15, ST 09:10-18:10,
  FR-08C 06:10-21:50, Metro 05:45-22:00.
- Routes in data with no CDA PDF: FR-04B, FR-08B, EX-16, FR-17, FR-02, FR-03B, PLAN-DD-TOUR, and Metro RED / ORANGE.
- Stop names are as printed by CDA (with some spelling variants, e.g. "Barahkahu", "Golra sharif", "Pims Metro Station").
  They have not been reconciled with the data stop names.

SAFETY / HOUSEKEEPING
- Only PDFs from www.cda.gov.pk were downloaded. They were read with a text extractor only. No raw files were copied
  into data/ or research/incoming. data/systems was not edited. The CDA app / Kentkart API was not touched.
- A 1-byte write-test file research/incoming/_t.tmp was left behind (gitignored by *.tmp). Nothing was deleted.
