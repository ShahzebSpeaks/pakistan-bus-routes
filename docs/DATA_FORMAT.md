# Data format

Each file in `data/systems/` describes one transit system: one operator or brand in one city. File name = `<id>.json`.

## System

| Field | Type | Notes |
|---|---|---|
| `id` | string | kebab-case, unique, equals the file name |
| `city` | string | id from `data/cities.json` |
| `name`, `name_ur` | string | English and Urdu names |
| `operator` | string | who runs or regulates it |
| `mode` | `bus` · `brt` · `metro_rail` · `feeder` · `electric_bus` | used for speeds, map style and GTFS route type |
| `website`, `helpline`, `payment` | string or null | |
| `fare_rules` | Fare | default for all routes |
| `hours` | `{ "start": "07:00", "end": "22:00", "notes": "" }` or null | |
| `last_verified` | `YYYY-MM-DD` | when someone last checked the whole file |
| `sources` | Source[] | |
| `routes` | Route[] | |

## Fare

```json
{ "type": "distance_slab", "currency": "PKR", "slabs": [{ "up_to_km": 15, "fare": 80 }, { "up_to_km": null, "fare": 120 }], "concessions": "…", "as_of": "2026-03", "source_url": "https://…" }
```

`type` is `flat` (use `flat`), `distance_slab` (use `slabs`, where the last slab has `up_to_km: null`), `stop_count` (slabs counted in stops), `range` (use `min` and `max` when only the cheapest and full-route fares are published; the planner scales by distance and marks the fare approximate) or `unknown`.

## Route

| Field | Type | Notes |
|---|---|---|
| `id` | string | as printed on the bus: `R1`, `EV2`, `FR-04A` |
| `name`, `name_ur` | string | usually "Terminal A - Terminal B" |
| `variant` | string | `red`, `pink`, `ev`, `brt`, `metro`, `feeder`, `electric`, `regular`, used for default colours |
| `color` | `#RRGGBB` or null | official line colour |
| `status` | `operational` · `under_construction` · `planned` · `suspended` · `unverified` | only operational and unverified routes are used by the planner and GTFS |
| `launched` | date or null | |
| `length_km`, `headway_min` | number or null | |
| `hours` | object or null | overrides the system hours |
| `fare_override` | Fare or null | overrides the system fare |
| `women_only` | boolean | Pink buses. The planner skips these unless the user opts in |
| `mode` | optional | override the system mode for this route |
| `shape` | optional `"straight"` | skip road routing, for example for elevated corridors |
| `stops` | Stop[] | ordered, one direction |
| `stops_confidence` | `high` · `medium` · `low` | high means official or at least 2 agreeing sources |
| `sources` | Source[] | |
| `notes` | string | conflicts between sources, recent changes |

## Stop

| Field | Type | Notes |
|---|---|---|
| `name`, `name_ur` | string | |
| `lat`, `lon` | number or null | WGS84 |
| `coord_source` | string or null | `osm:node/123`, `wikipedia`, `manual` = verified. `auto:osm:…`, `auto:nominatim:…`, `auto:same-name:…`, `auto:interpolated` = generated by `npm run data:geocode` |
| `is_station` | boolean | BRT or metro station with a platform |

Stops with the same name within 450 m across routes of a city are merged into one stop in the app, which is how interchanges are found.
